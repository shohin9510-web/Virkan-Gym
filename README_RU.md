# Virkan Gym v1.5.0

Android-приложение для персонального тренировочного плана.

## Реализовано

- Название приложения: **Virkan Gym**.
- Пользовательская золотая эмблема установлена как иконка приложения.
- RIR/RPE полностью отсутствуют.
- Фиксированное расписание:
  - Пн — Грудь + трицепс;
  - Вт — Кардио + бассейн;
  - Ср — Отдых;
  - Чт — Спина + бицепс;
  - Пт — Отдых;
  - Сб — Ноги + бассейн;
  - Вс — Отдых.
- Пресс — первым и последним упражнением каждого тренировочного дня.
- Отдельный раздел **«Базовые веса всех упражнений»**.
- Автоматическая прогрессия силовых весов: **+2,5 кг каждую неделю** от базового веса.
- Дата начала программы задаётся в настройках.
- Бассейн:
  - длина — 50 м;
  - база — 200 м;
  - прогрессия — +50 м каждую неделю;
  - стиль — произвольный, без выбора стиля.
- Таймер отдыха.
- Отметка выполненных подходов.
- Экран прогресса веса.
- Данные сохраняются локально через SharedPreferences.

## Сборка APK через GitHub Actions

1. Загрузить содержимое проекта в GitHub-репозиторий.
2. Открыть вкладку **Actions**.
3. Выбрать **Build Virkan Gym APK**.
4. Нажать **Run workflow**.
5. После успешной сборки скачать артефакт **Virkan-Gym-v1.5.0-debug**.

APK внутри артефакта: `app-debug.apk`.
