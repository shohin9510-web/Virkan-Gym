# Virkan Gym 1.9.0

Автономное Android-приложение с интерфейсом HTML/JavaScript внутри защищённого локального WebView. Пакет `tj.virkan.gym`, Android 8.0 и выше, версия 1.9.0 (19).

## Возможности

- Редактор постоянной программы; просмотр и перенос тренировок.
- Индивидуальные базовые веса, недельные прибавки и время отдыха; у тяги верхнего блока шаг 5 кг.
- Пресс первым и последним упражнением; прогрессия повторений или дополнительного веса.
- Выполненные подходы исчезают из списка и сохраняются в прогрессе с фактическими весами и повторениями.
- Предыдущие результаты, восстановление подходов, таймер с автоматическим скрытием после отдыха.
- Бассейн 50 м, базовая дистанция 200 м, прибавка 50 м в неделю.
- Подтверждение пустого профиля, сохранение на устройстве, импорт/экспорт JSON.
- Без RIR/RPE, анатомических картинок, регистрации, облачной синхронизации, шагомера и интеграции с часами.

## Структура

`web/` — исходный интерфейс v1.9. `app/` — Android-оболочка Java. `tests/` — проверки логики. `scripts/` — проверка проекта, подготовка SDK и Gradle Wrapper.

Ветка `build/virkan-gym-v1.9` подготовлена отдельно от старой версии в `main`. Начальный проверенный пакет исходников автоматически разворачивается первым шагом CI; затем в этой ветке сохраняются обычные читаемые исходные файлы. Контрольная сумма пакета: `02886d4871691053d6c6e9f1d88825597dfcf198e8cd0fbd13f1428e65893659`.

## Сборка

В GitHub: Actions → Build Virkan Gym APK. Сборка запускается при изменениях в `main`, `master` и `build/virkan-gym-v1.9`; доступен ручной запуск. Сначала выполняются структурные проверки и Node-тесты, затем `gradle :app:assembleDebug :app:lintDebug`.

Результаты находятся в артефактах `Virkan-Gym-v1.9.0-debug` (APK, SHA-256 и номер коммита) и `Virkan-Gym-v1.9.0-source` (исходный проект).

Локально: Java 17, Android SDK 35, Gradle 8.9. `bash scripts/install-sdk.sh`, затем `./gradlew :app:assembleDebug :app:lintDebug`. Gradle Wrapper скачивается официальным скриптом с проверкой SHA-256.

## Данные и ограничения

Перед переходом сохраните JSON-копию в прежней HTML-версии, затем восстановите её в приложении. Пакет `tj.virkan.gym` отличается от прежнего `tj.fitplan.free`: не удаляйте старое приложение до переноса данных.

Это тестовая debug-сборка, не релиз для магазина. Без постоянного ключа подписи APK из разных запусков CI могут не устанавливаться друг поверх друга. Для стабильной подписи предусмотрены четыре GitHub Actions secrets: `VIRKAN_KEYSTORE_BASE64`, `VIRKAN_STORE_PASSWORD`, `VIRKAN_KEY_ALIAS`, `VIRKAN_KEY_PASSWORD`. Не публикуйте ключи и пароли в репозитории. Перед переустановкой делайте JSON-копию.

Таймер хранит время окончания и пересчитывается при возвращении в приложение; гарантированный сигнал при закрытом приложении не реализован. CI-сборка и проверки кода не заменяют проверку установки, файлового выбора, сохранения и таймера на реальном телефоне.
