# Установка Virkan Gym 2.0

1. Старую версию не удаляйте. В ней сохраните резервную копию JSON.
2. Установите Virkan-Gym-2.0.0-preview.apk. Значок называется Virkan Gym 2.0, приложение устанавливается отдельно от 1.9.
3. При необходимости восстановите JSON через настройки новой версии.
4. Импорт сохраняет вашу прежнюю программу. Чтобы включить новый цикл, откройте «Настройки → Редактор постоянной программы → Загрузить новый трёхнедельный план», выберите дату начала и сохраните. История не переписывается.
5. Проверьте базовые веса. Значения вводите сами; брусья — без дополнительного груза.
6. «Фото выполнения» открывает две справочные фотографии, а весь каталог находится в настройках. Это не ранее показанные сгенерированные плакаты.
7. После подхода таймер отсчитывает 90 секунд и исчезает. Бассейн — последняя отдельная отметка, без метров и обязательного времени.

Это тестовая сборка. Перед переустановкой всегда сохраняйте JSON.
