# Virkan Gym 2.2 — проверочная Android-сборка

Новый трёхнедельный цикл по последнему сообщению пользователя. Неделя 1: Пн бицепс+трицепс; Чт грудь+спина. Неделя 2: Пн бицепс+грудь; Чт трицепс+спина. Неделя 3: Пн спина+бицепс; Чт грудь+трицепс. Вт шея+трапеция; Ср кардио; Сб ноги+дополнительные группы; Пт и Вс отдых. Пресс до/после зала и бассейн последним: Пн, Ср, Чт, Сб.

Веса и шаги сохранены из пользовательского Word. Не назначены отсутствующие базы ТР05/ТР06 и нагрузки для шеи. Во вторник блок зарезервирован; состав задаётся пользователем. Неуточнённые названия пресса и противоречивые повторения остаются выбираемыми в сверке документа. Подъём на трапецию имеет отдельную запись 3×60 повторений и не использует вес подъёма гантелей через стороны. Планка измеряется в секундах.

Уведомления: отдельные дни и время для программы на сегодня, напоминания, незавершённой тренировки и бассейна. По умолчанию выключены. Android разрешение запрашивается при включении. Точное время доступно при специальном разрешении; без него возможна задержка. Канал звука/баннера настраивается в Android. После перезагрузки и смены часового пояса расписание восстанавливается. После принудительной остановки необходимо снова открыть приложение. Действия: открыть тренировку и отложить на 30 минут. Уведомления используют текущий план и переносы, завершённые тренировки/бассейн подавляются. В HTML — только настройки и предпросмотр, не фоновый будильник.

90-секундный таймер и короткий Web Audio сигнал сохранены. Это НЕ новая гарантированная фоновая служба таймера; звук при блокировке нужно проверять отдельно.

52 проверки JavaScript и 9 интерфейсных сценариев пройдены локально в изолированном Chromium с искусственным localStorage. Это не проверка Android-телефона. Android-компиляция и lint должны быть подтверждены отдельным запуском CI.

## Перенос
Новый debug package: tj.virkan.gym.preview22. Старый APK не удалять; экспортировать JSON и импортировать в новую версию. Импорт сохраняет старую программу. Для нового цикла: Настройки → Сверка плана → выбрать оставшиеся варианты при необходимости → применить с нужной даты. Либо редактор постоянной программы → загрузить новый план → сохранить. Дата базовых весов из Word (23.10.2026) сохраняется; её можно изменить самостоятельно. Цикл в текущей логике отсчитывается полными 7-дневными периодами от заданной даты.

Используется debug-подпись, если постоянный ключ не задан в GitHub Secrets. Ключи не коммитятся. main и предыдущие ветки не изменяются.
