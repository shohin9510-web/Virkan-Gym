# Virkan Gym 2.0 — тестирование

Новая версия создаётся в отдельной ветке. main и сборка 1.9 не заменяются.

## Безопасный переход

Перед тестированием сохраните JSON из 1.9. APK 2.0 имеет отдельный пакет `tj.virkan.gym.preview20` и может стоять рядом со старой версией. Не удаляйте старое приложение.

После импорта прежней копии сохраняется старая пользовательская программа. Для нового трёхнедельного цикла откройте «Настройки → Редактор постоянной программы → Загрузить новый трёхнедельный план», выберите дату действия и сохраните. Базовые веса вводите или проверяйте сами.

Фото выполнения — отдельные справочные изображения из Free Exercise DB с указанием источника, не сгенерированные плакаты. Они не заменяют проверку техники тренером.

Это debug-сборка для тестирования, не выпуск в магазине. Автоматические тесты и компиляция не заменяют проверку на реальном телефоне.
