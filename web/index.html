Профиль

Базовые веса

Прибавка задаётся отдельно для каждого упражнения. Для тяги верхнего блока — +5 кг в неделю. Для пресса выберите прибавку повторений или дополнительного веса. Остальные шаги тоже настраиваются.

Все группы

Пресс: скручивания и подъём ног настраиваются отдельно. В режиме повторений нагрузка растёт числом повторений; в режиме веса — килограммами дополнительного отягощения. Вес тела к нему не прибавляется.

Расчёт: база + ваш шаг × число прошедших недель. Повторное открытие не добавляет нагрузку заново. Для гантелей учитывается вес одной гантели, для штанги — общий вес с грифом.

ВАША НЕДЕЛЯ

Редактор постоянной программы

Настройте дни, состав и порядок упражнений. Пресс настраивается отдельно для каждой недели и дня. Бассейн всегда после зала. Изменения относятся к будущим тренировкам, а не к архиву.

По умолчанию — следующий понедельник. Можно выбрать сегодня. Начатые, завершённые и перенесённые тренировки не переписываются.

Незаданные прибавки пресса не назначаются автоматически. Параметры прогрессии задаются в «Базовые веса всех упражнений → Пресс». Здесь меняется число подходов и повторения для режима с дополнительным весом.

Программа

Эта дата задаёт начало расчёта нагрузки и исходного трёхнедельного цикла. Каждые следующие 7 календарных дней прибавляется индивидуальный шаг веса . Пропуски сами по себе не останавливают расчёт.

Бассейн всегда последний: только «Выполнено / Не выполнено». Отдых после подходов фиксирован: 90 секунд.

Резервная копия

Сейчас в приложении

Сначала появится предварительный просмотр копии. Данные заменяются только после вашего подтверждения. Перед заменой создаётся защитная копия в локальном хранилище.

Защитная копия не заменяет отдельный JSON-файл. Удаление приложения или очистка его данных удаляет и локальные копии. Для переноса между телефоном и браузером используйте JSON. Данные не отправляются на сервер.
